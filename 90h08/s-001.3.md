##### References to Criminal Code

1.3 The Lieutenant Governor in Council may make regulations governing transitional matters that may arise as a result of amendments to the Criminal Code (Canada), including regulations providing that, despite subsection 1 (4) of this Act, references in this Act to provisions of the Criminal Code (Canada) shall be read as references to other provisions of the Criminal Code (Canada), or shall be read as including references to other provisions of the Criminal Code (Canada), for the specified period. 2017, c. 26, Sched. 4, s. 1.

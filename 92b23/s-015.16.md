##### Scope of agency’s powers

15.16 (1) A registered code agency may exercise the powers and perform the duties specified in this Act and the building code in respect only of the functions and the building specified in a particular appointment. 2002, c. 9, s. 28.

##### Confidentiality

(2) A registered code agency shall not collect, use or disclose information except in accordance with the building code. 2002, c. 9, s. 28.
